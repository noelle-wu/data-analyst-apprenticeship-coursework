# Data Analyst Apprenticeship — Coursework

Practical exercises completed during my Level 4 Data Analyst Apprenticeship
(Distinction, 2025–2026). Each folder contains hands-on work from one module —
completed during and after live sessions.

> 🔎 Looking for my end-to-end portfolio project (forecasting & linear
> regression)? It lives in its own repository: [link once created]

## Modules

| Folder | Module | What's covered |
|---|---|---|
| `python-and-pandas/` | Introduction to & Further Python and Pandas | Core Python, DataFrames, cleaning and manipulating data with Pandas |
| `data-visualisation/` | Data Visualisation | Charts and visualisations to communicate insights to technical and non-technical audiences |
| `time-series-analysis/` | Time Series Analysis: Foundations | Analysing and modelling data that changes over time using Pandas and NumPy |
| `maths-for-data-analysis/` | Maths for Data Analysis | Probability, statistical significance and linear algebra foundations |
| `machine-learning/` | Introduction to Machine Learning | Fundamental ML concepts — training and applying models in practical scenarios |
| `sql/` | Databases and SQL | Querying and retrieving structured data — SELECTs, joins, aggregations |
| `web-scraping-and-apis/` | Web Scraping, Text-Mining, JSON and APIs | Retrieving and processing data from web sources and APIs |
| `data-science-for-business/` | Data Science for Business | Applying data science to real business problems, including ethics and legislation |

## Tools used

Python (Pandas, NumPy) · SQL · Jupyter Notebooks

## Notes

- All exercises use training datasets provided by the course — no real
  organisational or personal data appears in this repository.
- These are learning exercises; my applied, end-to-end analysis work is in my
  portfolio project repositories.
